# The certificate authorities the built application trusts. A frozen
# interpreter looks for them at the path they occupied on the build machine,
# which exists on no user's computer, so the store comes up empty and every
# HTTPS call fails. PyInstaller collects this package's bundle through its own
# hook; control_center/workspace.py falls back to it only when the machine
# turns out to have no trust store of its own.
certifi
